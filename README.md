# MP3 Player for iPhone

Download the app and the Windows installer from [the latest release](https://github.com/PiggyChu620/MP3Player-iOS-Releases/releases/latest).

Download **MP3Player-iPhone-Windows-Installer.zip**, extract it, and double-click **Install-iPhone.cmd**. It downloads the verified IPA and prepares the Windows installation tools. Connect your iPhone, tap Trust, then sign in with your own Apple ID in Sideloadly and press Start. Windows approval, Apple sign-in and iPhone Trust/Developer Mode prompts cannot be automated. Full instructions are in **IPHONE-INSTALL.md** under Assets.

Requires iOS 17+. The IPA is unsigned until Sideloadly signs it for your own phone. It cannot be installed by tapping it in Safari. No Mac or paid Apple membership is required for this route. A free Apple account requires signing renewal every seven days. Sideloadly automatic refresh needs the paired PC. Refresh renews signing; it does not download new app releases. Run the installer again for updates, keeping the same Apple ID and bundle ID. Do not uninstall the app between updates.

This repository contains compiled downloads and public instructions only, not application source, music, cookies, passwords or signing credentials. The Android releases use a separate repository. The first iPhone version supports Files import and direct audio downloads, not Android's YouTube downloader.

Official help: [Sideloadly](https://sideloadly.io/faq), [Apple signing limits](https://developer.apple.com/help/account/basics/about-your-developer-account).
